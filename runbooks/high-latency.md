# Runbook: рост p95 latency

## Сигнал

`vision_latency_ms` превышает SLO в течение 10 минут при нормальном error rate.

## Диагностика

1. Сравнить request rate, batch size и p95 по версии модели.
2. Проверить CPU/GPU utilization, память и число workers.
3. Сравнить SHA-256 активного artifact с последним стабильным release.
4. Проверить рост разрешения/размера входных файлов и время декодирования.
5. Выполнить контролируемый smoke request напрямую, минуя proxy.

## Восстановление

Ограничить concurrency или размер batch, вернуть стабильный artifact, увеличить replicas только после исключения утечки памяти. Зафиксировать timeline, затронутые версии и p95 до/после изменения.
